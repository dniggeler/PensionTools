## Available Tool

### `financial_projection`

Calculates detailed financial projections for retirement savings.

**Key Features:**
- Month-by-month calculations
- Compound interest application
- Variable retirement credits by age
- Detailed projection tables
- Summary statistics

**Example Usage in Claude:**
> "Calculate a retirement projection starting with 500,000 CHF, 1.5% annual interest, from 2025 until age 70, with retirement at age 65"

## Implementation Details

### Based On
- **Interface**: `ISavingsProcessProjectionCalculator`
- **Implementation**: `SingleSavingsProcessProjectionCalculator`
- **Location**: `Application\Bvg\`

### Calculation Algorithm
1. Determine technical birth date from retirement date and age
2. Iterate month-by-month from start to final age
3. Apply pro-rated retirement credits
4. Calculate compound interest monthly
5. Update year-end balances
6. Track important dates and milestones

### Data Flow
```
Input Parameters
    ?
InvestmentCalculatorService
    ?
ISavingsProcessProjectionCalculator
    ?
Monthly Calculations Loop
    ?
RetirementSavingsProcessResult[]
    ?
JSON Response
```

## Architecture Highlights

- **Clean Architecture**: Separation of concerns across layers
- **MCP Protocol**: stdio-based JSON-RPC 2.0
- **Dependency Injection**: Microsoft.Extensions.DependencyInjection
- **Logging**: Configured to avoid stdio interference
- **Error Handling**: Comprehensive error handling at all levels

## Performance

- **Startup**: Fast (minimal dependencies)
- **Memory**: Scales with projection period length
- **CPU**: O(n) where n = months in projection range
- **Concurrent**: Can handle multiple projections
